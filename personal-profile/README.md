# Personal Profile

A personal profile web application. The frontend is built with Next.js, TypeScript, and Tailwind CSS. Backend and database work will be added in later phases.

## Requirements

- Node.js 20.9 or later
- npm

## Frontend

```powershell
cd frontend
npm install
npm run dev
```

Open http://localhost:3000 to view the app. The temporary home page is in `frontend/app/page.tsx`.

Copy `.env.example` to `.env.local` in `frontend/` when local environment variables are needed.
